# PigeonPetApp 信鸽桌宠

Desktop pet shaped like a pigeon with **LAN file transfer**. Send a file to get a 6-digit extraction code; the receiver enters the code to receive it instantly. Supports **cross-subnet transfer, resumable downloads and encrypted transmission**. Built-in tools: weather, Pomodoro timer, sticky notes, calculator.

鸽子宠物形态的桌面软件，支持**局域网文件传输**（发送文件生成 6 位提取码，对方输入即可接收），支持**跨网段、断点续传、加密传输**。内置天气、番茄时钟、便签、计算器。

## Usage 使用

1. **Sender 发送方**: choose a file → send → get a 6-digit code（选文件 → 发送 → 得到 6 位提取码）
2. **Receiver 接收方**: enter the code → confirm → the file is received automatically（输入提取码 → 确认 → 自动接收）
